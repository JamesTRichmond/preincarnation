# Loot record (not the county)

This folder is the grounds pass from the session that checked 768 candidate definitions: a source, a real use, ownership, and a fourteen-year return. It is a record. It is not the game.

The playable county stays the 320×240 canvas. You are one person. Death is a chapter. The Marble Vein is the only plot. Maeve, the shovel, and the lantern that returns to the off-hand live in `items.ts` and `rules.ts`. Saves stay in `localStorage`.

The candidate catalog is not an import and it is not mounted on the canvas. A DOM ledger of generated nails, cards, and caches would cover the screen and invent a second plot. Those objects are not placed in Middlebury.

`scanPacks` looks for external JSON packs under `support/`, `artifacts/`, and `src/`. None ship with this repo. The broken fixture is rejected and is not part of the 768.
