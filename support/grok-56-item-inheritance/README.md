# Item inheritance

Ellis comes back fourteen years after a death. A carried object stays that object. Years do not tax the bread. A unique source does not grow back because the life ended.

This pack is the persistence contract from the item-inheritance session: definition id, instance id, world source, ownership, player storage, placement, restoration history, and era identity stay distinct. Thirty-six stories cover a donated tool used by a successor, a restored instrument inherited as itself, a cache exposed by changing land, a family object recognized decades later, and an ordinary object that becomes historical without being copied by a common node.

## Not on the walk

The session also drew a Return Ledger, a full page of beats and dossiers. Mounting that page on `/` would cover the Green and the 320×240 canvas. That conflicts with the vision, so the ledger is not in this tree and nothing under `src/` imports this pack.

The county save is untouched. `SAVE_VERSION` stays 8 and `preincarnation.save.v1` is not read or written here. This pack's own contract (`preincarnation.item-inheritance`, versions 0, 1, and 2) is only exercised by its tests.

Death in these tests is not a corpse run. An unfinished sale aborts. A vanished building puts Ellis's property back in storage unless that site's authored policy is a cache. Unique, heirloom, and quest sources stay consumed. A renewable node may yield once each era, and that yield is never an heirloom.
