# Fourteen Winters ledger

A keeping room for the seventy-two, the objects, and the papers. It is not the walk.

Ruling #64: no second game. This module does not get a route, a title-screen link, or a place on `/`. "Fourteen winters" in the county is still the time that passes when you die. This ledger does not retcon that sentence and does not touch the Marble Vein.

The county save key `preincarnation.save.v1` is not read or written. This ledger uses `fourteen-winters-keeping-room-v1`.

Nothing in `src/` imports this folder. The room, the table, and the grounds are here so the rules can be tested and so a later import, if James asks for one, does not invent a second card law.
